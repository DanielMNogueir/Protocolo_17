## scout

Use case: stylized-concept. Production transparent pixel-art spritesheet for Protocolo 17. Reference image 1 is Lia, exact pixel-art craft, outlined material rendering and 3/4 overhead camera style reference ONLY. Reference image 2 is official corrupted maintenance robots concept, use its FIRST ROW twin-rotor scout as design starting point, elevate the finish to Lia quality. Create ONLY the SCOUT: small agile round gunmetal drone, two circular ducted propellers on outriggers, teal enamel edge panels, brass fasteners, tiny worn yellow safety marks, exposed cables and single magenta sensor/corrupted core, front underslung pulse emitter. Charming industrial silhouette yet threatening. Real crisp pixel clusters, dark outlines, upper-left light, no smooth 3D look. Transparent background, no floor, no shadows, no text or gridlines. EXACT uniform 4-column by 4-row grid, 16 equally sized cells with generous transparent gutters. Each sprite same scale and centered at identical position within cell. Frames row-major: row1 headings RIGHT, DOWN-RIGHT, DOWN, DOWN-LEFT. Row2 LEFT, UP-LEFT, UP, UP-RIGHT. Row3 repeats row1 as second animation frame with propeller spokes quarter-turn and articulated arms slightly flexed; row4 repeats row2 as second animation frame. Keep body proportions and heading identical between corresponding frames; vary rotor blades mechanically. These are true directional perspective views, never rotate a flat sprite. Entire drone always within its cell. Square 1024x1024 sheet, 256x256 cells. Every cell occupied by exactly one drone. Preserve actual transparency.
